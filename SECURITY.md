# Security policy

This plugin runs as root and changes firewall state, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private vulnerability reporting instead:
**Security > Report a vulnerability** on this repository.

Include the cPanel/WHM version, OS, which firewall tools are installed, and steps to reproduce.
We aim to acknowledge reports within 5 working days.

## Supported versions

Only the latest release is supported.
